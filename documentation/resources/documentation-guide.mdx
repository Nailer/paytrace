## Preview locally

```bash
npm i -g mint
cd documentation
mint dev           # http://localhost:3000
mint broken-links  # check internal links
```

## Writing conventions

1. **Technical first, then plain English.** After each technical explanation, add:
   ```mdx
   <Accordion title="In plain English" icon="lightbulb">
   Simple explanation for non-technical readers.
   </Accordion>
   ```
2. **Quote real behavior.** Error messages, limits and field rules must match the code exactly.
3. **No overclaiming.** Say *testnet*, *test USDC*, *not audited*, *not bank settlement*.
4. **Use components purposefully:** `<Steps>` for procedures, `<Warning>` for irreversible or risky actions, `<Check>` for checklists, Mermaid for flows.
5. **Every new page** must be added to `navigation` in `docs.json`.
