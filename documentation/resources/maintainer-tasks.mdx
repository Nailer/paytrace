These are tasks that need the owner's accounts, wallet or judgment. Everything else is already done or documented.

## 1. Publish these docs on Mintlify

<Steps>
  <Step title="Merge the documentation branch">Merge the pull request that adds `documentation/` into `main`.</Step>
  <Step title="Create a Mintlify deployment">
    In the [Mintlify dashboard](https://dashboard.mintlify.com), create a **new** documentation project (don't reuse an existing one like `veri-pay` or `attestable`).
  </Step>
  <Step title="Connect GitHub">
    Install the Mintlify GitHub App on `Nailer/paytrace`, choose branch `main`, and enable **monorepo** mode with docs path `/documentation` (the folder containing `docs.json`).
  </Step>
  <Step title="Pick a subdomain">e.g. `paytrace` → `paytrace.mintlify.app`. Optionally add a custom domain later.</Step>
  <Step title="Check the deploy">Open the site, click through each tab, and confirm the logo shows in light and dark mode.</Step>
  <Step title="Link it">Add the docs URL to the repository's README and GitHub "About" section, and to the landing page/footer of the app if you like.</Step>
</Steps>

<Accordion title="In plain English" icon="lightbulb">
The docs are written and saved in your GitHub repo. To put them online you just tell Mintlify "my docs live in the `documentation` folder of this repo." After that, every time you push changes to that folder, the website updates by itself.
</Accordion>
