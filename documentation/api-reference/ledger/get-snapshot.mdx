---
title: "Get workspace snapshot"
api: "GET https://paytrace-tau.vercel.app/api/ledger"
description: "Return the signed-in merchant's full workspace: receiving wallet, requests, funding and reviews."
---

Requires a valid merchant session (hosted) or a loopback host (local).

<Accordion title="In plain English" icon="lightbulb">
"Give me everything in my dashboard." The workspace page calls this every 15 seconds.
</Accordion>

### Response

Returns a [`LedgerSnapshot`](/api-reference/data-types#ledgersnapshot).

<RequestExample>
```bash cURL
curl https://paytrace-tau.vercel.app/api/ledger \
  -H 'Cookie: paytrace_session=…'
```
</RequestExample>
