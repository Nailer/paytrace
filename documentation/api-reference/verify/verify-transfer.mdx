---
title: "Verify a transfer (read-only)"
api: "POST https://paytrace-tau.vercel.app/api/verify"
description: "Public: run Layer-1 chain verification for any hash, recipient and amount. Changes nothing."
---

<Accordion title="In plain English" icon="lightbulb">
A free fact-checker for Monad USDC payments. It never saves or changes anything.
</Accordion>

### Body

<ParamField body="transactionHash" type="string" required>`0x` + 64 hex.</ParamField>
<ParamField body="recipient" type="string" required>Nonzero address.</ParamField>
<ParamField body="expectedAmount" type="string" required>Positive decimal string, ≤ 6 decimals.</ParamField>

Body ≤ 4096 bytes. If an `Origin` header is sent it must match this site.

### Response

`200` with a [`ChainProof`](/api-reference/data-types#chainproof) for every outcome, including `amount_mismatch`, `no_transfer`, `reverted`, `not_finalized` and `unavailable`. Non-200 only for invalid input, rate limits, and provider/integrity failures.

<RequestExample>
```bash cURL
curl -X POST https://paytrace-tau.vercel.app/api/verify \
  -H 'Content-Type: application/json' \
  -d '{"transactionHash":"0x…","recipient":"0x1a2b…9f0e","expectedAmount":"1"}'
```
</RequestExample>
