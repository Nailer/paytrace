## Design system

Defined entirely in `src/app/globals.css`.

| Token | Value |
| --- | --- |
| Surfaces | Warm ivory |
| Navigation | Ink / deep forest `#19342e` |
| Actions | Teal `#237a62` |
| Body font | DM Sans 400/500/600/700 (self-hosted via Fontsource) |
| Heading font | Manrope 500/600/700 |
| Icons | lucide-react |

Status is always conveyed with **text and icon**, not color alone. Desktop uses a sidebar; mobile uses compact navigation; tables collapse to records; details open as a side sheet (full-screen on mobile). Layouts were inspected at 390 px with document width equal to viewport width.

<Accordion title="In plain English" icon="lightbulb">
The look is calm and "bank-like": cream backgrounds, dark green, teal buttons. Statuses always have words and icons, so people who can't distinguish colors still understand them. It works on phones as well as desktops.
</Accordion>

## Accessibility

- Visible focus states, keyboard-operable controls.
- `role="alert"` for errors, `role="status"` for progress.
- `aria-label`s on icon-only buttons (dismiss, refresh, close).
- Reduced-motion support was a stated design requirement.

## Security headers (all routes)

From `next.config.ts`:

| Header | Value |
| --- | --- |
| `X-Content-Type-Options` | `nosniff` |
| `X-Frame-Options` | `DENY` |
| `Referrer-Policy` | `no-referrer` |
| `Permissions-Policy` | `camera=(), microphone=(), geolocation=()` |
| `Content-Security-Policy` | `frame-ancestors 'none'; object-src 'none'; base-uri 'self'` |
| `X-Powered-By` | removed (`poweredByHeader: false`) |
