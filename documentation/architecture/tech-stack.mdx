## Runtime dependencies

| Package | Version | Role |
| --- | --- | --- |
| `next` | 16.3.8 | App Router framework, Route Handlers, SSR. Security headers in `next.config.ts` |
| `react` / `react-dom` | 19.2.8 | UI |
| `@libsql/client` | ^0.18.0 | SQLite/Turso client used by `Ledger` |
| `siwe` | ^3.0.0 | EIP-4361 message construction and signature verification |
| `ethers` | ^6.17.0 | `getAddress` (EIP-55 checksum) for SIWE; also used by `siwe` for signature recovery |
| `lucide-react` | ^0.468.0 | Icons |
| `@fontsource/dm-sans` | ^5.2.0 | Body font (self-hosted) |
| `@fontsource/manrope` | ^5.2.0 | Heading font (self-hosted) |

<Accordion title="In plain English" icon="lightbulb">
These are the building blocks: **Next.js/React** for the website, **libSQL** for the database, **SIWE** for "sign in with your wallet," **ethers** for wallet address handling, and **lucide** plus two fonts for the look.
</Accordion>

## Standards implemented

| Standard | Where |
| --- | --- |
| ERC-20 `transfer` / `Transfer` event | Checkout calldata; verifier log decoding |
| EIP-1193 provider API | Checkout and wallet login |
| EIP-3085 `wallet_addEthereumChain` | Checkout network setup |
| EIP-3326 `wallet_switchEthereumChain` | Checkout network switch |
| EIP-4361 Sign-In with Ethereum | Wallet sign-in |
| EIP-55 checksum addresses | SIWE message address |
| JSON-RPC 2.0 | RPC client |
