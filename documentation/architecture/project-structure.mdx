<Accordion title="In plain English" icon="lightbulb">
- `src/app` = the pages people visit and the server endpoints.
- `src/components` = the interactive screens.
- `src/lib` = the brains: checking the blockchain, saving data, login security.
- `tests` = automatic checks that prove it all works.
- `scripts` = helper tools for hosting and backups.
</Accordion>

## Path alias

`@/*` resolves to `./src/*`, e.g. `import { ledger } from '@/lib/ledger'`.

## Ignored files

`.gitignore` excludes `node_modules/`, `.next/`, all `.env*` except `.env.example`, `.data/`, `*.sqlite*`, `.vercel/`, build info and test reports. **Your local database and wallet evidence are never committed.**
